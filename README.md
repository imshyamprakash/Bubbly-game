# Bubbly — Number Hunt

Bubbly is a quick browser game about focus and reflexes. Find the bubble that matches the target number before the 60-second round ends. This project was built during a workshop at IIT Palakkad.

## How to play

1. Select **Start playing**.
2. Find and select a bubble with the target number.
3. Earn 10 points for each correct bubble and try to beat your personal best.

The game works with a mouse, touch screen, or keyboard. Your personal best is saved in your browser on your device.

## Run the game

Open `index.html` in a modern browser. The project uses plain HTML, CSS, and JavaScript, so it does not need a build step or package installation.

To publish it with GitHub Pages, open the repository's **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.

## Built with

- HTML for the page and game controls
- CSS for the responsive layout and bubble animations
- Vanilla JavaScript for scoring, the timer, replay, and saved best score
